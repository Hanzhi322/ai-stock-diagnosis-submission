# 测试说明

## 复现方式

推荐 Node.js 24。安装依赖后运行：

```bash
npm test
npm run typecheck
npm run build
```

自动测试模拟外部服务，不要求真实密钥，不产生模型费用。实际服务验证使用服务端配置的凭证，和单元测试结果分别记录。

## 浏览器主链路

已检查的本地交互包括：

- 提问与快捷问题生成真实 AI 解读，点击后滚动到结果区；等待时展示正在诊断，完成后原位更新。
- 空输入保留校验提示并聚焦输入框，不误显示新结果。
- 左侧四项目录与内容标签对应；点击切换并滚动定位，重复点击当前目录也有效。
- 财报证据抽屉、估值原始倍数、历史区间与新闻原文链接可访问；新闻冲突保留提示。
- 搜索、筛选、空状态恢复；Markdown/JSON 导出包含本轮资料。
- 股票对话推荐问题、连续追问、新闻引用及错误重试提示。
- 初版已检查 390px 布局；本轮桌面页面检查了新增资料面板与证据抽屉。响应式仍需在目标设备上复核。

## 真实服务验证

本地已验证 Groq 返回 `mode: llm`，以及扶摇价格、日线、估值和 iFinD 新闻实际返回。综合解读使用本轮行情与媒体线索，不只复述固定财报。

本次线上发布的接口状态、诊断和聊天调用结果，统一写入 `VERIFICATION.json` 的 `online` 字段。记录只保存非敏感的结果摘要、模式和证据编号，不保存密钥。

公开首页无需身份凭证返回 HTTP 200；真实诊断和公司问答返回 `mode: llm`；价格、日线、估值取得有效数据。iFinD 首次上线曾在初始化请求阶段触发 20 秒超时；改用服务端 TLS 直连同一官方地址后，生产请求约 7.8 秒返回五条新闻。TLS 证书校验保持启用；没有将密钥移到浏览器、引入第三方代理或使用本地样例替代查询。后续模型和数据调用结果见验证记录。

## 重点异常与边界

- 缺失、鉴权失败或限流显示具体状态，不用模拟行情、空值补零或“近期无事件”代替。
- 模型失败时诊断保留资料并明确标注规则模式；聊天保留问题并允许重试。
- 正常新闻片段不因“尚未核验”就被误判为事实冲突；只对检测到的明确冲突额外标记。
- 价格下跌与财报增长可并列，但不自动认定某条新闻导致价格变化。
- 估值指标已取得不等同于完成同行比较或高低估结论。
- 交易指令、确定性预测与收益承诺请求转为研究边界说明，不执行交易。

## 安全与交付检查

发布前检查 `.gitignore`、候选源文件、浏览器构建、部署压缩包及 Git 历史。`.env.local`、依赖、调试记录和本地运行目录不进入提交包；真实密钥不进入源代码或客户端。依赖许可证保留。

公开演示使用服务商账户额度；当前未提供生产级持久化配额、压力测试或多租户隔离。测试通过不是收益、安全或服务可用性的保证。
