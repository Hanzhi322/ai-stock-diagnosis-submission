# 90 秒演示脚本

可选视频，不是必交项。录屏时只展示产品，不显示密钥或配置文件。

0–15 秒：展示宁德时代、报告期和公告日期，说明使用可追溯公开财报。说明当前是规则模式还是已经连接模型，不混淆。

15–35 秒：点击“增长质量”。介绍为什么制造业需要同时看利润、现金流、存货和应收，不用一个好/坏分数代替分析。

35–60 秒：点开“利润在增长，现金流增速却未同步”。展示财报事实、原值、公式、口径差异、原文页码。说明现金流绝对额高于归母利润，但增速落后；不能直接断定利润失真。

60–75 秒：追问存货和应收，展示期末对年初口径。再问当前估值，看到数据缺口，而非编造实时行情。

75–90 秒：打开证据清单，筛选矛盾信号；导出研究记录。结束于产品边界：当前仅宁德时代快照，下一步接金融数据接口与生产级模型用量管理。
