# 演示参考（约 90—150 秒）

1. 说明研究对象为宁德时代，目标是理解经营状态并验证依据，而非输出买卖建议。
2. 点击“综合诊断”，展示页面自动定位与等待提示，完成后查看 AI 综合解读。
3. 对照财报、价格、历史走势、估值和新闻各自的时点。打开现金流矛盾证据，查看原值、公式与口径差异。
4. 打开“行情与新闻”，展示区间折线、估值指标及新闻片段；点开一条新闻的来源和核验提示。
5. 在“问问证研”输入“当前估值判断还缺哪些证据？”，展示模型解释与引用。
6. 展示研究记录导出，结束时说明同行估值、历史分位与新闻完整原文尚未全部核验。
