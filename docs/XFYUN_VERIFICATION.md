# 讯飞接入与验收记录

## 验证范围

2026-09-27，在腾讯云独立分支的本地生产构建上，使用讯飞星辰 MaaS `spark-x2.5-1.7b` 实际调用，并查询公开的宁德时代资料。测试问题为人工构造，不包含私人对话、持仓或账户资料。密钥只用于对应供应商请求头，不进入提示、Git 或此记录。

## 根因与修正

- 腾讯云原 Groq 接口返回 403；这是上游访问拒绝，不能通过放松回答校验解决。腾讯云副本接入已授权的讯飞模型。
- 讯飞默认推理曾消耗约一千个输出 token，使回答正文为空；仅对该模型设置 `enable_thinking=false` 和 `max_tokens=2000`。
- 长提示中的数值模板曾导致非法 JSON、额外字段及正文缺失。给该轻量模型提供简洁来源资料与 JSON 示例；仍使用相同来源、数值及交易边界校验。
- 修正了信息缺口提示中沿用旧行情缺失状态的问题；局部内部处理提示不进入正文；可核实句子继续展示。
- 推荐追问过滤机器人对用户的建议句，保持用户提问口吻。

## 实际接口结果

| 场景 | HTTP | 返回模式 | 耗时 | 结果 |
| --- | --- | --- | --- | --- |
| 公司介绍 | 200 | `llm` | 7.50 秒 | 取得预期模式与正文 |
| 问候后连续提问公司业务 | 200 | `llm` | 1.27 秒 | 取得预期模式与正文 |
| 现在还缺哪些关键信息 | 200 | `llm` | 5.76 秒 | 取得预期模式与正文 |
| 利润增长与现金流支撑 | 200 | `llm` | 7.71 秒 | 取得预期模式与正文 |
| 查询当前股价 | 200 | `data` | 0.01 秒 | 取得预期模式与正文 |
| 财报、股价、新闻综合诊断 | 200 | `llm` | 4.38 秒 | 取得预期模式与正文 |

本轮五项解释请求返回 `mode=llm`，为真实讯飞输出；股价请求返回 `mode=data`，直接由行情字段生成，不算模型成功。正文人工复核：未出现先前空正文或修复失败提示；信息缺口没有把已取得的全部财报或行情说成缺失；现金流同时保留绝对额与增速差异；综合诊断保留估值基准和媒体核验限制。

自动化验证：108 项测试通过、0 失败；Next.js standalone 生产构建与其中的 TypeScript 检查通过；`git diff --check` 通过。异常和边界覆盖沿用 [测试说明](TESTING.md)，另增加讯飞输出额度、简洁提示、内部提示局部剔除与追问口吻的回归测试。

补充走势核验：首次补测遇到供应商连接超时，重试后实际模型返回“所查历史区间首尾价格走弱、下降”，并明确不能据此确认涨跌原因。该方向由已取得的前复权收盘数据计算后提供给模型，避免模型自行推算。此项是相同资料的直接模型调用与回答校验，未计入上表六项完整接口验收。

## 不夸大的边界

- 这轮是本地生产服务的真实调用，不是腾讯云实例验收。腾讯云还须更新代码与三项 LLM 变量后测试。
- 轻量模型的表述深度、分类与引用选择仍有限；本轮公司介绍未主动给出引用，另一个公司业务追问及现金流回答提供了对应来源。界面已有公司与财报来源可独立核查，不能将结构校验等同完整事实核验。
- 这六个案例不代表所有问法、新闻细节、复杂归因或长期并发都已通过。数字查询、失败降级与模型输出须区别记录。
- 未声称已完成腾讯云全部功能或国内不同运营商网络验收。原 GPT Site、main 分支和原提交压缩包不随此分支更新。
